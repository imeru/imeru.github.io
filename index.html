Nest Observer is a personal-use application being configured to observe an owner's Google Nest thermostat through Home Assistant and Google's Smart Device Management API.

What the application does

It records indoor temperature, heating setpoints, humidity when available, heating activity, and Eco status. Weather data can be combined with these observations to study the home's thermal response.

Observation before automation

The initial phase observes device states. No thermostat control automation is configured. Future thermal models and predictive control will first be evaluated in simulation; any real control requires a separate decision by the owner.

This public website provides project information only. It has no thermostat dashboard, Google sign-in, or connection to the home's Home Assistant server.

Data and access

The application is intended only for its owner's authorized household device. Device records and authorization credentials are stored in the owner's local Home Assistant installation. They are not published on this website.
